# Code of Conduct

G-Trans is a small open source project. Keep discussions technical, direct, and
respectful.

## Expected Behavior

- Be clear about the problem, reproduction steps, and tradeoffs.
- Critique code and decisions, not people.
- Assume public issues and pull requests may be read by users evaluating the
  project.
- Avoid posting secrets, credentials, private logs, or sensitive translation
  content.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Publishing someone else's private information.
- Repeated off-topic or disruptive comments.
- Security reports that intentionally expose private data in public threads.

## Enforcement

Maintainers may edit, hide, or remove comments and close issues or pull
requests that do not follow this code of conduct.
